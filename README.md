🎬 Movie Explorer

A dynamic and interactive web application that allows users to search and explore movies from around the world. Built using modern frontend technologies and integrated with real-time APIs and Firebase for cloud storage.

🚀 Features

🔎 Search for any movie globally

🎞 Watch official trailers

⭐ Add movies to a personalized wishlist

👥 View cast and actor details

📝 Read detailed movie descriptions

☁ Store wishlist data securely using Firebase

🛠 Tech Stack

HTML5 – Structure

CSS3 – Styling & Responsiveness

JavaScript (ES6) – Functionality & Logic

Movie API – Fetch real-time movie data

Firebase – Cloud storage for wishlist data
🔥 How It Works

User searches for a movie.

The application fetches data using a Movie API.

Movie details, cast, and trailer are dynamically displayed.

Users can add movies to their wishlist.

Wishlist data is stored securely using Firebase.
